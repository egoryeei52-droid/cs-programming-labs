## Задание 1. Работа с переменными

Создать четыре переменные со следующими значениями

| Переменная            | Значение  |
| --------------------- | --------- |
| `station_name`        | `"Ocean"` |
| `active_sensors`      | `18`      |
| `average_temperature` | `21.6`    |
| `is_online`           | `True`    |

Вывести значение и тип каждой переменной в указанном порядке

```text
Ocean <class 'str'>
18 <class 'int'>
21.6 <class 'float'>
True <class 'bool'>
```

## Задание 2. Вычисление выражения

Вычислить выражение

```text
(a + b) * c^2 - a div b + a mod b
```

В записи программы использовать операторы Python для возведения в степень, целочисленного деления и остатка от деления

Вывести результат в формате

```text
Результат: 101
```
